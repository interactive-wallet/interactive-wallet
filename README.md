# Interactive Wallet

Internet of Services Lab 2026

## Setup

After cloning, do this once:
```
# Fetch dependencies
git submodule init
git submodule update
# Build the VON
cd von-network && ./manage build
```

Start the backend:
```
# Start the VON
cd von-network && ./manage start
```

Stop the backend:
```
cd von-network && ./manage stop
```
